# Srushti's Birthday

A responsive, no-build birthday page for Srushti Kulkarni, celebrating August 7.
The page uses plain HTML, CSS, and JavaScript; no dependencies or build command
are required.

## Preview locally

Open `index.html` in a browser.

## Deploy on Netlify

1. Push this repository to GitHub, GitLab, or Bitbucket.
2. In Netlify, choose **Add new project** → **Import an existing project**.
3. Connect the Git provider and select this repository.
4. Leave the build command empty. The publish directory is `.` (also set in
   `netlify.toml`).
5. Choose **Deploy**. Future pushes to the selected branch will deploy
   automatically.

You can also use Netlify Drop to deploy the project folder without Git.
